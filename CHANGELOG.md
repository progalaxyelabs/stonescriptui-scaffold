# Changelog

All notable changes to the StoneScriptUI Scaffold project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-22

### Added
- Initial release of StoneScriptUI Scaffold
- Complete Todo App example with localStorage persistence
- Comprehensive documentation (README.md)
- HTMS Quick Reference guide
- Security Guide for innerHTML warnings and XSS prevention
- Todo App test results documentation
- Hot module reload support with Vite
- DOM utilities with innerHTML warning system
- Event handling via data-action pattern
- Context and state management
- Hash-based routing
- Conditional rendering with @if/@else
- List rendering with @each
- Two-way data binding with bind attribute
- Component system
- TypeScript support
- Development and production build scripts

### Documentation
- README.md - Complete guide to getting started with HTMS
- HTMS-QUICK-REFERENCE.md - Quick syntax reference
- SECURITY-GUIDE.md - XSS prevention and innerHTML migration guide
- TODO-APP-TEST-RESULTS.md - Test results for the example todo app

### Dependencies
- @progalaxyelabs/htms-cli: ^0.3.0
- @progalaxyelabs/htms-compiler: ^0.3.0
- TypeScript: ^5.3.3
- Vite: ^5.0.10

### Features
- **Zero Runtime**: Compiles to vanilla TypeScript/JavaScript
- **Type Safety**: Full TypeScript support with compile-time validation
- **Security First**: Built-in innerHTML warnings to prevent XSS
- **Hot Reload**: Automatic browser updates during development
- **Framework Agnostic**: Works with any backend or frontend setup
